# Джерела й ліцензії логотипів видань

Фолбек для новин-цитат конкретного видання без власного фото (див.
`newsbot/source_logos.py`). Обмежений список найчастіших видань в атрибуції
заголовків — решта видань лишаються без картинки, як і раніше.

Усі файли — офіційні логотипи видань з Wikimedia Commons, шаблон ліцензії
`{{PD-textlogo}}` (простий текст/геометрична форма не досягає порогу
оригінальності для авторського права — public domain), але лишаються
торговою маркою відповідного видання: використання лише для позначення
джерела новини (редакційне/номінативне використання), не для реклами чи
використання від імені видання. Растеризовано з оригінальних SVG у PNG
(прозорий фон) для компонування на картці каналу — вихідні SVG лежать
поруч для довідки.
